01 / Visão geral

Do seu carro a uma frota inteira.
Mais clareza em cada trajeto.

Pensado para uso pessoal e para equipes que acompanham vários veículos, o OBD Monitor reúne um painel web e uma etapa inicial de conexão com adaptadores OBD-II Bluetooth. A proposta é tornar informações importantes mais fáceis de entender e consultar.

03 / Prévia do painel

Perceba os sinais. Cuide antes que virem problema.

A proposta é identificar códigos de falha e acompanhar sinais como temperatura do líquido de arrefecimento, tensão da bateria e nível de combustível. Alertas podem ajudar a investigar um problema mais cedo e planejar o cuidado do veículo.

DEMO / 01Prévia simulada: o painel ainda não recebe dados ao vivo. Leituras disponíveis variam conforme o veículo e o adaptador; os alertas ajudam no acompanhamento, mas não substituem uma avaliação mecânica.

04 / Como funciona hoje

Duas partes, em estágios diferentes.

O painel e o conector fazem parte da mesma proposta, mas ainda não estão ligados entre si.

01 / PAINEL WEB

Explore a interface

O dashboard apresenta as áreas de diagnóstico, manutenção, segurança e preferências com dados de demonstração.

02 / ADAPTADOR

Verifique o Bluetooth

Um script Python para Windows verifica o Bluetooth ativo e tenta conectar a um adaptador OBD-II compatível.

03 / PRÓXIMA ETAPA

Conecte as duas pontas

A integração entre leituras reais do veículo e o painel web é um próximo passo do projeto, junto com histórico e alertas.

iEstado do projeto: protótipo de demonstração. O script de conexão é uma etapa inicial e depende de adaptador compatível, Bluetooth e ambiente Windows; os dados exibidos nesta página não vêm de um veículo conectado.
